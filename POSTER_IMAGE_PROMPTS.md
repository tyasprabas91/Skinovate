## 💡 TIPS UNTUK GENERATE

### Untuk Midjourney:
- Gunakan `--v 6` atau `--v 5.2` untuk quality terbaik
- Tambahkan `--style raw` untuk hasil lebih natural
- Contoh: `/imagine prompt: [paste prompt 1] --v 6 --style raw`

### Untuk DALL-E 3:
- Paste prompt langsung, DALL-E akan otomatis interpret
- Bisa request revisions jika hasil kurang sesuai

### Untuk Stable Diffusion:
- Use model: Realistic Vision, DreamShaper, atau SDXL
- Negative prompt: "feminine, pink, girly, childish, cartoon, low quality"
- Steps: 30-50, CFG: 7-9

### Untuk Canva/Design Tools:
- Gunakan prompt sebagai guide untuk layout
- Combine dengan template modern healthcare apps
- Use provided color codes
